\subsection*{1. System Prompt \& Architectural Grounding (Session Bootstrap)}
\begin{quote}
\small
\textbf{Lead Engineer Direction:} \\
\textit{``We are architecting FINN, a mobile-first financial investment agent for an Indian equity investor. Build strictly across two modalities: (1) Push: a 60-second executive daily brief featuring materiality-scored filings, YoY/QoQ results extraction, C-suite leadership profiles, and configurable anomaly triggers; (2) Pull: grounded on-demand equity research bounded strictly to primary sources (SEBI filings, Annual Reports, Concall Transcripts via Screener.in tables). Zero tolerance for generic AI slop or unformatted markdown. Implement tiered cost routing (deterministic regex at ₹0, Flash for structured JSON extraction, Pro for deep synthesis) with SHA-256 caching. Execute phase-by-phase with verifiable production checkpoints.''}
\end{quote}

\vspace{0.5em}
\subsection*{2. Phase Iterations \& Key Engineering Prompts}

\paragraph{Iteration 1: Schema Architecture \& Serverless Decoupling}
\begin{itemize}
    \item \textbf{Engineer Instruction:} \textit{``Design a normalized PostgreSQL schema with \texttt{pgvector} for 768-dimensional embeddings and \texttt{tsvector} for keyword search. Isolate heavy batch PDF downloads and vector embeddings into GitHub Actions cron runners to prevent Vercel serverless execution timeouts (~60s limit).''}
    \item \textbf{Agent Execution:} Structured 10 core tables in \texttt{db/schema.sql} (including \texttt{llm\_cache}, \texttt{research}, and \texttt{chunks}). Formulated the disclosure prioritization formula $\text{Priority} = \text{Category Weight} \times \text{Materiality} \times \text{Position Weight}$, ensuring routine filings (ESOPs, trading windows) are mathematically deprioritized into compact collapsible counters.
\end{itemize}

\paragraph{Iteration 2: Flagship Logic --- Promised vs. Delivered Audit Scorecard}
\begin{itemize}
    \item \textbf{Engineer Instruction:} \textit{``How do we extract genuine management guidance from concall transcripts without letting the LLM hallucinate or summarize boilerplate corporate optimism?''}
    \item \textbf{Agent Execution:} Implemented two-stage pipeline: (1) Gemini 2.5 Flash structured JSON extraction isolating quantitative metrics ($\le 25$-word verbatim quotes + exact transcript page references); (2) Gemini 2.5 Pro synthesis cross-auditing claims against subsequent audited financial results to produce an Executive Credibility Score (e.g. \textit{8/10 Met}) and divergence analysis.
\end{itemize}

\paragraph{Iteration 3: Mobile Terminal Design \& Ergonomics}
\begin{itemize}
    \item \textbf{Engineer Instruction:} \textit{``Build a calm editorial finance theme in Next.js 14 App Router: dark surface (\#0B0D10), electric teal accent (\#2DD4BF), Inter font with tabular numerals for Rupee amounts ($\text{₹}$, Cr, \%), thumb-reachable bottom navigation across 4 tabs (Brief, Alerts, Ask, Portfolio), and centered mobile container frame for desktop evaluators.''}
    \item \textbf{Agent Execution:} Implemented Framer Motion gesture animations, results cards with YoY/QoQ comparative matrices, management transition cards with enriched professional backgrounds, and configurable alert slider sheets.
\end{itemize}

\paragraph{Iteration 4: Build Optimization, Route Handlers \& Unified Vercel Deploy}
\begin{itemize}
    \item \textbf{Engineer Instruction:} \textit{``Ensure API endpoints resolve seamlessly under Next.js native Route Handlers and serverless functions without CORS mismatches, and package offline snapshot fallbacks to ensure evaluators never encounter empty states.''}
    \item \textbf{Agent Execution:} Resolved Next.js static asset build traces, implemented native \texttt{app/api/*} handlers alongside FastAPI routes, validated local endpoint tests (100\% pass rate), and deployed the unified project to Vercel production.
\end{itemize}

\textbf{Selective AR Chunking} & Ingesting Full 400-page Annual Reports & Selective extraction of high-signal sections (MD\&A, Auditor notes, Segments, Borrowings) optimizes retrieval accuracy and token spend. \\ \hline
\textbf{Snapshot Fallbacks} & Pure Database Dependency & Guarantees zero downtime or empty screens during evaluator reviews under exchange API rate limits or network cold starts. \\ \hline
